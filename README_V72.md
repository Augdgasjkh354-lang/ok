# FewerBandits v7.2 — 封地野心与派系共推

基线：v7.1，目标游戏：《骑马与砍杀：战团》1.174，Module System 1.171（通过 Python 3 兼容编译器编译）。

## 新内容

1. **长期封地野心**：每 72 游戏小时更新各国在职领主的野心值（10–99），根据名望、性格、既有封地数量及旧日分封怨恨计算。领主会选择一个属于本国、尚不归自己所有的城镇/城堡/村庄作为长期觊觎的目标。已拥有目标时清除旧目标并重选；转投别国后也会重新评估。
2. **派系先行推举候选人**：王国将封地列入议事议程后，同一秘密派系的领主先独立核定一个共同候选人，结果写入派系领袖数据。候选人按个人野心、历史怨恨、领土贫富、声望、与国王及派系成员关系以及当前觊觎地评选。受囚禁、争议性过高、投奔外国的候选人不会入选。每位盟友投票时读取同一结果，消除 v7.1 “必须等领袖先投票”的顺序问题。盟约忠诚度低于 35 的领主继续独立投票。选元帅继续采用 v7.1 旧规则。
3. **围绕国王封赏的派系竞争**：原版议事和国王最终裁决仍生效。赢得封地的派系成员降低不满、加强彼此盟约；落选的派系候选人将积累分封不满，降低对国王及获封者的关系，其支持者也会产生不满。当前版本只影响由原版 AI 宫廷议程正常授予 NPC 的封地；其他人工强制分封、创建角色时初始分封不触发此争斗回调。
4. **询问封地野心**：与领主面对面交谈，新增“你觊觎哪块封地？你的盟友支持谁？”对话。与玩家关系低于 10 时拒绝透露；其余报告长期目标、野心程度、分封怨恨以及议程存在时共同推举的候选人。全部新增对话已中文化。

## 保留功能

完整保留 v7 战后恩情/仇恨、亲族恩怨及追杀，v7.1 领主密盟、相互支援、互相庇护、盟约对话、普通/满级开局；等级62、四维属性63、有效技能10、熟练度699 的满级开局规则未变。兵种、物品、声音、资源、地图、菜单没有改动。

## 安装

1. 备份 `MountBlade Warband\Modules\TestMod\` 和已有存档。
2. 解压 `FewerBandits-v7.2.zip`，将压缩包内 `FewerBandits` 文件夹下的内容覆盖至 `Modules\TestMod\`；保留你当前完整的 `module.ini`、`map.txt` 与 `SceneObj`。
3. **不要**把 `TestMod` 改名；不要运行之前交接文件内的旧版 `install.bat`。
4. v7.1 旧存档可以作为继续测试的起点；建议另存新档后观察 AI。旧存档不会自动补记之前发生的封地争夺。

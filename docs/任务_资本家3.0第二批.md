## 0. 场景

你放给领主的贷款（Slot 945）和到期的战争贷款（Slot 957），他还不上的部分最后都会并进他欠你的账（Slot 874），之后只有他身上有钱、又走到你身边时才会自动还。没钱的领主就一直欠着。

本批加一个选项：领主欠你 ≥ 3000、财产又不够还时，你找他「谈钱的事」，可以提出拿他名下一座城镇四周的包税权抵账。成交后：
- 那座城的包税到期日（Slot 948）设为今天 + 28；
- 他的欠账（Slot 874）减去 min(欠账, 5000)；
- 不经手现金。之后领主到城里收租时，租税按已有的包税分流（`script_troop_does_business_in_center` 里读 948 的那段，第 23277 行附近）进玩家口袋，这段**不用改**。

5000 是城镇菜单直接买四周包税权的价钱，两边对得上。

**钱的流向**：没有现金转手。领主欠玩家的账（874）减少 5000，换成玩家四周的收租权；之后收到的钱，来自领主本该收的租税。能收回多少取决于那座城这四周的实际租税，可能多于 5000，也可能少于 5000，这是玩家要担的风险。

## 1. 新脚本 `af38_taxdebt_town`（`build/module_scripts.py`，追加在 `scripts` 列表末尾）

只读、不写任何状态。所有地方（入口条件、选项条件、NPC 回话、后果）都调它，保证几处判断一致。

- 参数 1：领主 troop。
- 输出：`reg0` = 可抵账的城镇（没有就是 0）；`reg1` = 这次能抵掉的金额（= min(874 欠账, 5000)，没有可抵的城就是 0）。
- 输出寄存器放到脚本最后再赋值（中途不调别的脚本也照这个写法）。

判断顺序（全部满足才返回城镇）：
1. 领主在 `active_npcs_begin`～`active_npcs_end` 之间；
2. 没被俘：`slot_troop_prisoner_of_party` = -1；
3. 欠账 `slot_af19_lord_owes_player`（874）≥ 3000；
4. 财产不够还：`slot_troop_wealth` < 欠账；
5. 在 `towns_begin`～`towns_end` 里找**第一座** `slot_town_lord` = 这位领主、并且包税不在期内的城镇。包税不在期内：`slot_af30_tax_farm_day`（948）≤ 今天（`store_current_day`），包括 0。
   找到第一座就停（用一个 `:found` 局部变量，`(eq, ":found", 0)` 守在循环开头，照 `af04_lair_kind` 的写法）。

## 2. 对话（`build/module_dialogs.py`）

### 2.1 新增行（**只能追加在文件末尾**，最后那个 `]` 之前）


说明：
- `reg42`（剩下的欠账）为 0 时，台词里会出现“剩下 0 照旧记着”。为避免这种情况，NPC 这一行拆成**两行**：第一行条件里多加 `(gt, ":left", 0)`，用上面的台词；第二行不加这个条件，台词改成「……也只能这样了。{s4}往后四周的租税归你收，这笔账就算两清了。」，下一状态相同。**两行顺序：有剩余的那行在前。**
- 对白里不称呼玩家为“老爷”“先生”；领主自己也可能是女性，不写带性别的自称。

# 任务：商队改成城镇自有（规格，待玩家确认）

玩家 2026-11-18 提出：城镇的钱有凭空来的部分，想把商队改成城镇自己的商队，不再是国家的，让城和城之间靠贸易真实地挣钱。
执行：Claude 或 GPT（动原版商队生成和贸易结算，牵扯面广）。

## 现在是怎样的（读代码确认）

- **生成**：`module_triggers.py` 的「Kingdom Parties」触发器每小时给每个活着的王国掷一次 10%，调 `create_kingdom_party_if_below_limit`。上限按王国的城镇数算：0 座 0 支、1 座 1 支、2 座 3 支、3 座以上 5 支。`cf_create_kingdom_party` 在这国随便挑一座城镇生成，护卫是模板里白给的。
- **本钱**：`af18_caravan_fund` 从出发城镇金库拿，补到 600，一次最多金库的四分之一。
- **做买卖**：`do_merchant_town_trade` 按物价变动算出 `total_change ÷ 2`，由成交城镇的镇民钱袋付（一次最多四分之一），钱进钱箱。
- **利润去向**：钱箱超过 600 的部分**每笔交易后马上交给所属国家的国王**（经济 2.0 第四批「商队上缴」）。所以现在商队挣的钱都进了国王口袋，城镇拿不到。
- **其他相关**：
  - 玩家入股商队（Slot 951）：按股从利润里分红。
  - 玩家自建商队（`af26_found_caravan`，阵营是玩家阵营）：利润进自己的钱箱，最多 36 支。
  - 白送商队（Slot 968）：玩家阵营从原版生成的，不拿利润。
  - 过路费、劫商队（`af18_*`）、解散退回出发城镇（`af18_caravan_disband`）。
  - 银行账（1057／1058）：商队没了转给国王（`af105_caravan_gone`）。

## 改成什么样

1. **东家是出发城镇**：每支电脑商队属于它的出发城镇（`slot_party_home_center`，原版已有，不新增 Slot）。阵营仍挂城镇所属的国家，所以打仗时照样会被敌国截。城镇易主后，商队跟着改挂新阵营。
2. **城镇自己组商队**：`create_kingdom_party_if_below_limit` 的商队分支改成在这国的城镇里挑：
   - 自有商队还没到上限：每 40 点繁荣一支，最多 3 支。
   - 金库够钱：组建费 2000，加上 600 本钱。
   - 优先挑最富的城；在那座城生成，不再随便挑。
   - 组建费的去向：雇护卫、买驮马，钱进本城镇民钱袋（城里人挣到）。不再白给。
3. **利润回东家**：钱箱超过 600 的部分不再交国王，改成**回出发城镇的金库**。国王照王室税的规矩抽一成，你当国王时按「税收」国策。
   - 回钱的时机：每笔交易后马上回（照现在上缴国王的写法，钱直接记账，不用商队真的跑回去）。
4. **钱从哪来**：照旧是成交城镇的百姓买货（镇民钱袋，一次最多四分之一）。这样金库的真实进项来自别的城的百姓，城和城之间靠贸易互相挣钱。
5. **然后收紧凭空的钱**（单列一步，等实机看过商队的进项再定）：金库每周凭空的本地生产「（繁荣×15＋700）×1.5」减半，或者只留「繁荣×5」。

## 待实机验收（实现后）

- 每座城的商队数和繁荣对得上，穷城没钱组不起商队。

- 国王的财产增长变慢（原来商队利润全归国王）。
- 打仗时商队照样被截，被截后钱箱归截的人，城镇损失本钱。

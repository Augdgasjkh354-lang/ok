## 玩家定下的原则
原版每周凭空给城镇商人补钱。真实的道理是：商人收的货会转卖给城里人，钱应该来自城里。原版每周刷新时清掉旧货、换上新货，现在把这件事当成真实的买卖来记账：
- **旧货被清掉** = 卖给了城里人 → 城镇金库付钱给商人；
- **新货补上** = 从本地作坊和村庄进货 → 商人付钱给城镇金库；
- 两者相抵，只结算差额。所以商人能拿回多少钱，取决于玩家卖给他多少、从他那买走多少。原版的随机补钱整个去掉。

## 新脚本（追加在 module_scripts.py 末尾）
1. `af24_stock_value(商人)`：输出 reg0 = 商人身上货物的总价值。
   - 遍历 `num_equipment_kinds` 到 `troop_get_inventory_capacity` 的每个格子，`troop_get_inventory_slot` 取物品（<0 跳过），`store_item_value` 取基础价值；食物等可分量的物品用 `troop_inventory_slot_get_item_amount` 按剩余比例算（拿不准就整件算，在提交说明里写明）。
   - 不考虑品质修饰（modifier），统一按基础价值，写进注释。
   - reg0 最后赋值。
2. `af24_settle_stock(商人, 城镇, 旧货价值, 新货价值, 上限)`：
   - 差额 = 旧 − 新。
   - 差额 > 0：城镇金库付给商人，最多付金库的四分之一（`slot_town_wealth`；照商队钱箱的规矩），付多少扣多少。
   - 差额 < 0：商人付给金库，最多付到商人身上的钱为 0。
   - **扫回**：结算后商人身上的钱超过"上限"的部分，转回城镇金库。上限：杂货商 3000，防具商、武器商 2000，马商 1200（原版补钱触发线的 2 倍）。
   - **新开局的本钱**：如果商人身上是 0、而且旧货价值也是 0（新开局第一次刷新），从金库给他一笔本钱：杂货商 1500，其余 750，同样最多拿金库的四分之一。旧存档里的商人身上本来就有钱，不会走这一条。

## 四个刷新脚本怎么改
每个商人：
1. 清空旧货之前：`af24_stock_value` → 旧货价值；
2. 原版照常清空、补新货（这部分不改）；
3. 补完新货之后：`af24_stock_value` → 新货价值；
4. 调用 `af24_settle_stock`；
5. **删掉**原版那几行"身上少于 1500／1000／600 就随机加一笔"。
注意：杂货商那个脚本的循环里城镇变量叫 `:cur_center`，另外三个叫 `:cur_town`，以源码为准。中间调用的脚本会改写 reg0，旧货价值要先存进局部变量。

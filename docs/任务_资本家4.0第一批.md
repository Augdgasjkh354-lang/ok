## 0. 场景

国王欠玩家的钱现在分散在三处，都是国王 Troop Slot：
- 874 `slot_af19_lord_owes_player`：欠账（放贷、到期战争贷款还不上的都并到这里）；
- 945 `slot_af29_loan_principal`：普通放贷的本息余额（见面时会并进 874，见 `af19_settle_debts`，`build/module_scripts.py:58105` 起）；
- 957 `slot_af33_warloan_principal`：战争贷款本金（到期才并进 874）。

各算各的，国王欠再多，对玩家也没有不同。本批：**玩家所在王国的国王**欠玩家合计 ≥ 10000、财产又不够还时，「谈钱的事」里多两个选项，国王拿原版本来就有的东西抵账：

- **A. 拿封地抵账**：国王从自己直属的封地里挑一处过户给玩家，按买城价（村庄 10000／城堡 30000／城镇 50000，`af33_center_price`）抵掉等额欠款。
- **B. 少抽成抵账**：国王以后从玩家缴获里少抽 5 个百分点（Slot 884，与城镇菜单「据理力争」同一个 Slot、同一个上限），抵掉 5000 欠款。

**钱的流向**：两个选项都不经手现金。A 是欠款 ⇄ 封地（价格与买城对话一致）；B 是欠款 ⇄ 以后少交的抽成。

**不做**：外国国王（封地过户要求玩家是本国封臣，抽成只对本国国王有效）；停战、元帅票、让国王出兵（会改国王 AI，越过 GPT 定的红线）。

## 1. 新脚本（`build/module_scripts.py`，追加在 `scripts` 列表末尾，最后那个 `]` 之前）

### 1.1 `af42_king_debt`（只读）

- 参数 1：troop。
- 输出：`reg0` = 合计欠款 = 874 + 945 + 957；`reg1` = 1 表示「王室债主」条件成立，0 表示不成立。**输出寄存器放到脚本最后再赋值**（中途调了 `troop_get_relation` 类脚本会改写 reg0）。
- `reg1` = 1 的条件（全部满足）：
  1. `$players_kingdom` 在 `npc_kingdoms_begin`～`npc_kingdoms_end` 之间；`$player_has_homage` = 1；
  2. `$players_kingdom` 的 `slot_faction_leader` = 参数 troop；
  3. 该 troop `slot_troop_prisoner_of_party` = -1；
  4. 合计欠款 ≥ 10000；
  5. `slot_troop_wealth` < 合计欠款。

### 1.2 `af42_king_debt_take`（写状态）

- 参数 1：troop；参数 2：要抵掉的金额 `:amount`（> 0）。
- 按顺序扣：先 874，再 945，最后 957。每一处扣 `min(该处余额, 剩余 :amount)`，写回。
- 945 扣到 0 时，同时把 946 `slot_af29_loan_day` 设 0；957 扣到 0 时，同时把 958 `slot_af33_warloan_due_day` 设 0（照 `af19_settle_debts` 第 58124～58125 行、`af33_settle_warloans` 第 60576～60577 行的写法）。
- 不输出寄存器。调用方保证 `:amount` ≤ 合计欠款。

### 1.3 `af42_crown_cut_room`（只读）

- 无参数。输出 `reg0` = 还能再减多少百分点（0 表示已到底）。
- 照 `mnu_af21_crown` 里「据理力争」成功分支（`build/module_game_menus.py:16259`～16266）算 `:max_off`：调 `script_af21_crown_cut_pct` 得当前 pct，加上 884 得 base_pct，`:max_off` = base_pct − 10；输出 `:max_off` − 884，`val_max` 0。

# 调查：哪些数据还没联动起来

调查日期：2026-11-11（Claude）。只查了源码，没改代码。基线 `main` 48bacec（试玩包十八＋经济 2.0 第一批）。

**进度**：玩家 2026-11-11 选了 ①③④⑤，已做完（见 README「v1.0 数据联动第一批」），待实机验收；② 和 ⑥ 暂缓。

## 0. 结论

- 普查了 Mod 全部 `slot_af*` Slot（约 200 个），看谁写、谁读。大部分 Slot 只在自己那一块里用，这是正常的（冷却日、令牌）。**真正值得接的是五六个「有分量、却只往一个方向流」的数据**：战乱度、粮仓、领主政绩、商路断供、村庄产业、装没听见。
- 现在的链条大多是「事件 → 数据」，缺「数据 → 别的系统」。最典型：**饥荒只扣繁荣，不会让村里乱、不会出流民**；**村子再乱也不少产一颗麦子**。
- 下面六条都**不新增 Slot、不新增数值**，只在已有的每日／每周／72 小时结算里多读一个已有数据，符合 AGENTS.md 的经济三规矩。

## 2. 候选联动（按推荐顺序，每条一个小场景）

### ① 饥荒 → 村里乱 → 出流民（0 新 Slot）

**场景**：苏诺被围了两个月，粮仓见底。周边几个村子的人开始往外跑，路上多了一队流民，有的投了匪帮。

- 挂接：`af17_weekly_hunger`（`module_scripts.py:57862`）里，粮仓不到 25% 时，除了繁荣 −1，再给这座城的附属村子（`slot_village_bound_center`）每周战乱度 +3（调 `af01_change_unrest`）。
- 流民现在只在**劫掠后 22 天内**、战乱 ≥40 才出（`af02_daily_update` 约 53510 行）。改成「劫掠后 22 天内，**或附属城镇粮仓不到 25%**」。
- 后面的连锁全是现成的：战乱高 → 匪帮来安家（`af04_find_home`）、领主政绩变差、传闻提到。
- 风险：只是多一个条件，流民仍受「一村一队、6 天冷却、16 天消失」的上限。

### ② 战乱度 → 村庄少产（0 新 Slot）

**场景**：一个战乱度 80 的村子，田没人种，麦子比平时少三成；附近城里麦价上去，跑商的人有利可图。

- 挂接：`center_get_production` 末尾（和经济 2.0 的战时军需同样写法）：村庄战乱度 ≥40 时，产量 ×(140 − 战乱度)/100，最低六成。
- 物价由原版 72 小时调价自己算，不发钱、不造货。和经济 2.0 接上：乱的地方货少，平稳的地方修磨坊才划算。
- 风险：要和繁荣对产量的影响叠加着看，免得双重惩罚太重；先只对战乱 ≥40 起作用。

### ③ 商路断了 → 领主去巡逻（0 新 Slot）

**场景**：三周没有商队进过瑞瓦切，城主领主带兵去附近的路上转了几天，土匪少了，商队又回来了。

- 挂接：`af08_refresh_jurisdictions` 算辖区混乱时，商路断供超过 21 天的城镇再加一点混乱度。领主巡逻（`af08_pick_patrol`）本来就挑混乱度最高的自家城去转，不用改。
- 这是个闭环：断供 → 巡逻 → 路上安全 → 商队回来 → 断供解除。
- 风险：混乱度也影响领主政绩，加的量要小，别让一个没商队的城把领主评成失职。

### ④ 领主政绩 → 他的村子好得快不快（0 新 Slot）

**场景**：一个勤政的领主，他名下的村子劫后恢复得快；一个失职的领主，村子乱了很久都平不下来。

- 挂接：`af01_daily_update` 里战乱度每天自然回落（约 53073 行，−1／−2）。按村子领主的 `merit − negligence` 多回落 1 或少回落 1。
- 让领主政绩从「传闻里的一句话」变成看得见的后果；你劝领主、举报领主也就有了真实分量。

### ⑤ 村庄产业 → 劫掠会损坏、账簿看得见（0 新 Slot）

**场景**：你出钱修的磨坊，被敌国领主劫村时烧了；村长说要 1500 才能修好。

- 就是 GPT 经济 2.0 的第三批。挂接原版劫掠完成那一刻（`af01_on_looted`，只结算一次），979 从 11～13 改成 21～23（已损坏），产能扣回去；村长对话加「出钱修」。
- 顺手把产业加进资产账簿（`af37_ledger`）一行。

### ⑥ 装没听见 → 领主议事时不推你（待查）

**场景**：你三次装没听见国王的召集，下回议封地，没几个领主愿意推你。

- `fb72_choose_caucus_nominee` 是领主在封地议事里推谁，读领主政绩。要先查玩家在不在它的候选里、怎么算分，才知道能不能把 888 接进去。查清再定，不先承诺。

## 3. 不建议做的

- 每帧或每小时扫全图算联动：都挂在已有的每日／每周／72 小时结算里。
- 新造「民心」「治安」之类的数：战乱度、繁荣、粮仓已经够用。
- 一次接太多：①②③会互相放大（饥荒 → 战乱 → 少产 → 涨价），要分批上，每批实测幅度。

## 4. 需要玩家决定

1. 先做哪几条。建议第一批 ①＋③（一条讲人，一条讲路，都是闭环），第二批 ②＋④，⑤ 跟经济 2.0 第三批一起做。
2. ② 的减产幅度：建议战乱 100 时只剩六成。

## 5. 第二轮候选（2026-11-11 续查，都 0 新 Slot）

### ⑦ 驻军欠饷 → 开小差（推荐）

**场景**：一座穷城的金库付不起驻军工资，过几周城外出现一队「某城开小差的士兵」，城里守军少了。

- 现状：每周金库结算（`module_simple_triggers.py` 约 502 行）先进账、再扣驻军工资，扣到负数就记 0，**欠的工资凭空消失，守军一个不少**。违反「有来有去」。
- 做法：付不起的那部分折成人数，从驻军里移走（最多每周一成），在城外生成一队现成的逃兵（`pt_af02_deserters`，沿用它的上限 7 队、16 天消失）。
- 连锁：城防变弱、城外多了逃兵（玩家可以收编，原版逃兵菜单现成）。

### ⑧ 流民进城 → 吃城里的粮（推荐，和 ① 是一对）

**场景**：饥荒村子的流民涌进邻近的安全城镇，那座城的粮仓也被吃紧，粮价跟着上去。

- 现状：流民到城里只给繁荣 +1（`af02_daily_update` 约 53470 行），城里的粮一点不少。
- 做法：到达时从目标城的粮仓（`slot_party_food_store`）扣一笔（按流民人数），粮价走现成的 `af17_grain_price_pressure`。
- 连锁：① 让饥荒外溢到别的城，玩家运粮、卖粮（饥荒价收粮已有）就有了真实需求。

### ⑨ 逃兵没了去处 → 投匪帮（待查）

**场景**：逃兵在外面晃了半个月没人收编，投了附近的匪帮，匪帮又壮大一截。

- 现状：逃兵队 16 天后直接删掉（`af02_daily_update` 约 53585 行），人凭空没了。
- 做法：删之前看附近有没有活着的匪帮老巢，有就把人数加给那个帮。要先查匪帮人数上限和 `af15_gang_recruit` 的记账方式。

### ⑩ 穷领主加派 → 村子乱

**场景**：一位打了败仗、财产见底的领主，向自己的村子多收了一笔钱，村里怨声载道。

- 做法：每周看领主财产（`slot_troop_wealth`），低于某个线时从他名下村子的村长钱袋拿一笔（`af13_village_purse` 扣、`af14_lord_wealth` 加），那个村战乱 +2。钱人都有来处去处。
- 风险：要和资本家 2.0 的「领主上门借钱」、政治 1.0 的「给穷领主拨军费」对齐门槛，别三件事一起压在同一个穷领主身上。

### ⑪ 包税太狠 → 附属村子乱

**场景**：你包了一座城的税，城下几个村子的战乱慢慢往上走；包税赚的钱和村里的安定之间要取舍。

- 做法：包税期内（948 > 今天），附属村子每周战乱 +1。只是一行，但会改变包税的划算程度，**要玩家拍板**。

### 查过、不用做的

- 战乱度 → 志愿兵：`update_volunteer_troops_in_village` 已经读战乱度。
- 匪帮挑肥商队：劫商队是玩家花钱指定的，不是匪帮自己挑，没有可接的地方。

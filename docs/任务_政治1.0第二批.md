## 0. 场景

你是斯瓦迪亚封臣，和国王关系不错。边境的一个村子被来回劫了几次，繁荣只剩 20。你自己拿 600 去救济（v0.1 的「出资救济」）不太够，于是去找国王：

- 「宫廷里的事」→「陛下，{村名}的百姓快撑不下去了，请拨些钱粮。」
- 国王信得过你，从王室财产里拿出 2000 第纳尔给村子。村长钱袋 +2000，战乱 −5，繁荣 +2；村里人记得这是你去求来的（村庄关系 +2）。国王财产少了 2000，**他下周给自己部队发饷就紧一点**。
- 30 天里你不能再向国王进言（不管这次是赈济还是拨款）。

另一回，王国正在打仗，有个领主穷得兵都快养不起了：

- 「陛下，{领主}那边快发不出军饷了，请拨些军费。」
- 国王拨 3000 进那位领主的财产（原版拿它发部队工资、招兵），不凭空生兵。那位领主记你的情（关系 +3）。

国王也可能拒绝：国库见底（拿不出最低额），或者信不过你。国库见底时不算用掉这次机会；信不过你时算用掉（不然玩家会连点刷骰子）。

**钱的流向**（经济规则 2：有来处有去处）：
- 赈济：国王财产（`slot_troop_wealth`）→ 村长钱袋（`af13_village_purse`）。
- 拨款：国王财产 → 领主财产。
- 一次最多拿国王财产的 1/4（经济规则：从钱袋往外拿钱一次最多 1/4）。
- 玩家一文不出、一文不拿。

## 2. 新脚本（`build/module_scripts.py`，追加在 `scripts` 列表末尾）

### 2.1 `af47_poorest_village`（只读）

- 参数 1：阵营。输出 `reg0` = 村庄 party 号（没有就是 -1）。输出寄存器放在最后。
- 在 `villages_begin`～`villages_end` 里找：`store_faction_of_party` = 参数阵营，且满足下面**任一**：
  - 繁荣 `slot_town_prosperity` < 40；
  - 战乱 `slot_af01_unrest` ≥ 20（读之前先 `call_script, "script_af01_ensure_village", 村`）。
- 在符合的村里挑**繁荣最低**的；繁荣一样挑战乱高的。
- 排除：村子正在被劫（`slot_village_state` = `svs_being_raided`，钱送不进去）。
- 一次扫 110 个村，只在对话条件里跑，不放触发器。

### 2.2 `af47_poorest_lord`（只读）

- 参数 1：阵营。输出 `reg0` = 领主 troop（没有就是 -1）。
- 前提：该阵营正在打仗——照 `module_scripts.py` 里 `:faction_is_at_war` 的写法（`try_for_range` `kingdoms_begin`～`kingdoms_end`，`slot_faction_state` = `sfs_active`，`store_relation` < 0）。没打仗直接返回 -1（和平时期不拨军费）。
- 在 `active_npcs_begin`～`active_npcs_end` 里找：同阵营、`slot_troop_occupation` = `slto_kingdom_hero`、不是国王（`slot_faction_leader`）、没被俘（`slot_troop_prisoner_of_party` = -1）、财产 `slot_troop_wealth` < 1000、对玩家关系 ≥ 0（跟你有仇的人你不会替他求钱）。
- 挑财产最少的。

### 2.3 `af47_petition`（写状态，进言的结算）

- 参数 1：种类（1＝赈济村子，2＝给领主拨军费）；参数 2：目标（村庄或领主）。
- 输出：`reg0` = 结果（1 答应，2 国库见底，3 信不过你），`reg1` = 实际拨了多少。**输出寄存器放到最后**（中途要调关系、繁荣、威名等原版脚本）。
- 步骤：
  1. 国王 = `$players_kingdom` 的 `slot_faction_leader`。
  2. 额度：赈济上限 2000、拨款上限 3000；实际额 = min(上限, 国王财产 ÷ 4)。
  3. **实际额 < 最低额**（赈济 500、拨款 1000）→ 结果 2，**不写 974**、不改关系，直接结束。
  4. 国王愿不愿意：关系 R = 国王对玩家（`script_troop_get_relation_with_troop`）。
     - R ≥ 20：答应。
     - 0 ≤ R < 20：掷骰，成功率 = 30 + R × 3 + 威名档 × 5（威名档：`af20_fame_total` → `af20_fame_tier`），钳在 5～90。
     - R < 0：拒绝。
     （对话条件已经拦住 R < 0，这里再查一遍防万一。）
  5. 不管答应还是信不过（结果 1、3），都写 974 = 今天 + 30。
  6. 答应（结果 1）：
     - `af14_lord_wealth`（国王, 0, 实际额）。
     - 赈济：`af13_village_purse`（村, 实际额）；`af01_change_unrest`（村, −5）；`change_center_prosperity`（村, 2）；村庄关系 < 30 时 `change_player_relation_with_center`（村, 2）（和 v0.1 救济一样，关系到 30 不再涨）；村子的封主是 NPC 领主且不是国王时，玩家↔该领主关系 +1；`af01_record_event`（村, 5）（复用「收到救济」事件，让村长对话能接上）。
     - 拨款：`af14_lord_wealth`（领主, 实际额, 0）；玩家↔领主关系 +3。
  7. 信不过（结果 3）：什么都不动，只写了 974。
- 不加玩家荣誉、声望（不是玩家出的钱；关系就是回报）。

## 3. 对话（`build/module_dialogs.py`，**文件末尾追加**，不改旧行）

### 3.1 入口（`lord_talk_court` 状态下的玩家选项）

共同条件：
1. 对方是本国国王：`$g_talk_troop` = `$players_kingdom` 的 `slot_faction_leader`；`$player_has_homage` = 1；`$players_kingdom` ≠ `fac_player_supporters_faction`（自立国王不用求自己）。
2. 冷却：974 = 0 或今天 ≥ 974。
3. 国王对玩家关系 ≥ 0。

- 选项 A「陛下，{s11}的百姓快撑不下去了，请拨些钱粮。」：再加条件 `af47_poorest_village`（`$players_kingdom`）≥ 0，村名存 `s11`，村号存 `$temp`（复用全局，见 `af43_press` 的用法）。
- 选项 B「陛下，{s11}那边快发不出军饷了，请拨些军费。」：再加条件 `af47_poorest_lord`（`$players_kingdom`）≥ 0，名字存 `s11`，troop 存 `$temp`。

**注意**：A、B 两个选项都用 `$temp` 存目标；对话条件是逐条算的，B 的条件会覆盖 A 存的 `$temp`。所以**后果里重新调一次** `af47_poorest_village`／`af47_poorest_lord` 拿目标，不要信 `$temp`。`s11` 也一样，后果里重存。

后果：`af47_petition`（1 或 2, 目标），把 `reg0` 存进 `$temp`、`reg1` 存进 `reg41`，然后**重新** `str_store_party_name`／`str_store_troop_name` 进 `s11`。去向 `af47_petition_reply`。

### 3.2 国王的回应（状态 `af47_petition_reply`，都回 `lord_talk_court`）

用 `$temp` 和种类区分（种类可另存：赈济时 `reg42` = 1，拨款时 2；回应条件里比 `reg42`）。中性称呼，不用「他」。

- 赈济、答应：「好。从内库拨 {reg41} 第纳尔给{s11}。告诉他们，我没忘了他们。」
- 拨款、答应：「拨 {reg41} 第纳尔过去。仗还要打，兵不能散。」
- 国库见底（两种都用）：「内库里也没几个钱了。等收了税再说吧。」
- 信不过你（两种都用）：「这种事，自有管事的人操心。你先管好自己的兵。」

文案可以照 Fable 风格再润色，但**意思和占位符不能变**。

## 0. 场景

本国在议某座城堡的归属。哈伦领主自己想要，跟你交情不错，于是派信使来：

「陛下在议{城堡}的归属。我想要这块地，希望你在议事时支持我。」

你可以：
1. **答应**——你的票当场投给哈伦。哈伦拿到地也好、没拿到也好，只要你守约，哈伦就欠你一张以后的封地票。这就是 v7.3 现成的「互惠换票」（`fb73_player_reciprocity`），直接调用。
2. **这一票不白给**——哈伦从自己的财产里付你一笔钱（最多 1500），你的票投给他。收了钱却改票，要把钱退回去，还算背约（信用 −18、关系 −12、记仇）。
3. **婉拒**——哈伦对你 −1。

**钱的流向**：要报酬时，领主财产（`slot_troop_wealth`）→ 玩家金币；背约或议程撤销时原路退回。一次最多拿领主财产的 1/4（经济规则）。

## 3. 新脚本（`build/module_scripts.py` 末尾追加）

### 3.1 `af51_find_lobbyist`（只读）

- 参数 1：0＝触发器里找人（要求冷却已过），1＝菜单里重找（冷却写的正是今天的也算，因为触发器刚写过）。输出 `reg0` = 来拉票的领主（没有为 -1）。输出寄存器放最后。
- 玩家前提（不满足直接返回 -1）：`$player_has_homage` = 1；`$players_kingdom` 在 `npc_kingdoms_begin`～`kingdoms_end`；当前议题是封地（`centers_begin`～`centers_end`）；玩家还没表态（stance = -1）；玩家没挂承诺（`slot_fb73_promise_candidate` = 0）。
- 领主条件：同国、`slto_kingdom_hero`、不是国王、没被俘；**自己在争这块地**：自己的 stance = 自己，或 `slot_fb72_desired_center` = 当前议题；对玩家关系 ≥ 10；`slot_fb73_debt_to` = 0（`fb73_player_reciprocity` 要求的）；5 天游说冷却（`slot_fb73_last_lobby_day` = 0 或已过 ≥ 5 天）；参数 1 = 1 时，`slot_fb73_last_lobby_day` = 今天也算通过。
- 挑对玩家关系最高的那位。

### 3.2 `af51_paid_vote_price`（只读）

- 参数 1：领主。输出 `reg0` = min(1500, 领主财产 ÷ 4)。

### 3.3 `af51_take_paid_vote`（写状态）

- 参数 1：领主（菜单里用 `af51_find_lobbyist`（1）拿到的）。输出 `reg0`：1 成交，0 没成（条件变了）。
- 重查 3.1 的玩家前提和「领主条件」里的同国、在争、没被俘；价钱 = `af51_paid_vote_price` ≥ 300。
- 成交：`af14_lord_wealth`（领主, 0, 价钱）；`troop_add_gold` 玩家 价钱；`fb73_record_promise`（`trp_player`, 领主, 议题, 领主, **5**）；玩家 `slot_fb73_paid` = 价钱；玩家 stance = 领主；嫌疑 `fb74_add_heat` 玩家 +10、领主 +6（照买票的量级）。

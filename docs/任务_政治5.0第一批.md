## 0. 为什么只做这两件

GPT 的政治 5.0《军功与军令》有四项，核对后：

| GPT 的 | 现状 | 判断 |
| --- | --- | --- |
| 本国军务簿 | 元帅（`slot_faction_marshall` 8）、王国 AI 状态（`slot_faction_ai_state` 4，`sfai_*`）、目标（`slot_faction_ai_object` 5）原版都有，但只有作弊菜单显示，玩家得挨个问领主 | **做**，只读页 |
| 元帅问责 | 原版每次王国 AI 更新时，元帅争议度 `slot_troop_controversy`（150）≥ 80 就自动撤掉，接着自动开新的元帅议题（`build/module_scripts.py` 约 23916 行，「Remove marshal if he has become too controversial」） | **做**：玩家申诉只抬争议度，撤换和重选全交给原版，不自己写 `slot_faction_marshall` |
| 战功作证 | 原版只记「最后是谁打下这座城」（`slot_center_last_taken_by_troop` 28），不记谁一起打了；要认定「并肩作战」得改攻城结算 | 不做（以后单独调查） |
| 履约记录 | 盾牌钱、装没听见（第六批）和原版的召集关系惩罚已经覆盖 | 不做 |

**丢城的证据**：原版 `give_center_to_faction` 在城易手时写 `slot_center_ex_faction`（62）= 旧主阵营（约 20674 行）；本 Mod 同时在 `slot_af06_capture_token`（784）记易手日（day+1，约 55984 行）。两者合起来就能可靠判断「本国 30 天内丢了哪些城」，不用新 Slot。

## 1. 场景

你是罗多克封臣。元帅带着大军去打斯瓦迪亚的城堡，没打下来；回头边境上一座城堡又被斯瓦迪亚拿走了。

- 营地 → 烽烟案头 → **查看本国军务**：「元帅：某某领主（争议度 62）。王国眼下：围攻{某城}。正与斯瓦迪亚、萨兰德交战。三十天内丢了：{某城堡}。你：正随军出征。」
- 你去找国王，「宫廷里的事」→「陛下，{某城堡}丢了，元帅难辞其咎。」
- 国王跟元帅交情深，护着他：元帅争议度只涨一点，国王对你也有点不快。交情一般：元帅争议度涨一截；涨到 80，原版下一次更新就把他撤了，宫廷开议新元帅（你可以用政治 1.0 的「眼下的议题」看）。
- 元帅当然记你的仇。

## 2. 新脚本（`build/module_scripts.py` 末尾追加）

### 2.1 `af52_lost_centers`（只读）

- 参数 1：阵营。输出：`reg0` = 30 天内丢掉的城堡／城镇数，`reg1` = 其中最近丢的一座（没有为 -1）。输出寄存器放最后。
- 扫 `walled_centers_begin`～`walled_centers_end`：`slot_center_ex_faction` = 参数阵营，`store_faction_of_party` ≠ 参数阵营，`slot_af06_capture_token` > 0 且（今天 + 1 − token）≤ 30。
- 最近：token 最大的那座。

### 2.2 `af52_army_text`（只读，结果拼进 `s40`）

- 前提：`$players_kingdom` 是正常王国（`npc_kingdoms_begin`～`kingdoms_end`），且玩家是封臣（`$player_has_homage` = 1）或雇佣兵（原版雇佣兵也跟元帅出征，`$players_kingdom` 有值即可）。不满足时：「你不属于任何王国，没有军务可看。」
- 各行（每一行各自包在 `try_begin` 里，**一行不满足不能把后面的行跳过**）：
  1. **元帅**：`slot_faction_marshall`。-1 或无效：「眼下没有元帅。」；是玩家：「元帅：你。」；否则「元帅：{名字}（争议度 {n}；到 80 会被撤换）。」
  2. **王国眼下**（`slot_faction_ai_state`）：0「按兵不动，各守各的地盘。」；1「元帅正在召集军队。」；2「围攻{目标}。」；3「劫掠{目标}。」；4「迎击敌军{目标部队名}。」；5「在{目标}一带清剿敌军。」；6「在办宴会。」；其他「按兵不动。」目标是 `slot_faction_ai_object`，状态 2、3、5 时是据点（`str_store_party_name`），状态 4 时是部队（同样 `str_store_party_name`，部队无效时省略名字）。
  3. **交战**：扫 `npc_kingdoms_begin`～`kingdoms_end` 和 `fac_player_supporters_faction`，`slot_faction_state` = `sfs_active`、`store_relation` < 0 的，名字用「、」连起来：「正与{…}交战。」没有：「眼下没有战事。」
  4. **丢城**：`af52_lost_centers`；> 0 时「三十天内丢了 {n} 座城，最近一座是{名}。」
  5. **你**：`check_quest_active` `qst_follow_army` →「你正随军出征。」；否则 `qst_report_to_army` →「元帅召你去报到。」；另外 `slot_af23_shield_paid` > 0 时追加「这次召集你已交了盾牌钱。」都没有就不写这一行。
- `s40` 的拼接照 `af46_agenda_text` 修正后的写法（中间用 `s41`～`s43`，最后才写 `s40`）。

### 2.3 `af52_appeal`（写状态，元帅问责的结算）

- 参数：无（读本国国王和元帅）。输出（最后赋值）：`reg0` = 结果（1 国王听进去了，2 国王护着元帅，0 没办成），`reg1` = 元帅争议度涨了多少。
- 重查 3.1 的全部条件，不满足 `reg0` = 0。
- 涨幅：`10 × min(丢城数, 3)`，再加威名档（`af20_fame_total` → `af20_fame_tier`）× 2。
- 国王对元帅关系 ≥ 30：国王护着元帅，涨幅减半；玩家↔国王关系 −2；结果 2。否则结果 1。
- 元帅：`slot_troop_controversy` += 涨幅（最高 100）；元帅↔玩家关系 −8；`slot_fb7_grudge` +10（最高 100）。
- 冷却：元帅 `slot_fb74_last_exposure_day` = 今天（复用 v7.4 的曝光冷却：问责也是当众指责，本来就该和「揭发」共用冷却）。
- **不**写 `slot_faction_marshall`，不调任何任免脚本：争议度够了，原版下一次王国 AI 更新自己会撤人、开元帅议题。

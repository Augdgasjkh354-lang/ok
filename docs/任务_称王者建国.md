# 任务：称王者夺城建国（第七国空位）

玩家 2026-11-18 定：**同一时间最多 1 个新国；城堡、城镇都能打；玩家可以当封臣；旧存档不要了（要开新档）**。
执行：GPT 或 Claude（动原版战和、据点归属、领主 AI，不适合 Muse）。第 4 步的普查可以交给 Muse。
新 Slot：**1048～1049**（已登记到 CLAUDE.md 和 AGENTS.md）。脚本前缀 `af104_`。

## 场景

1. 称王者的义军壮大后（≥150 人，Slot 997 记的胜仗 ≥3），每周挑一座**原国**的城堡或城镇，要求守军弱于义军，然后开过去。
2. 义军走到城下就用脚本结算，不走原版攻城。打赢了这座城就归她；打输了义军折损，30 天后才能再打。
3. 第一次夺城就**建国**：启用空位势力 `fac_kingdom_7`，用运行时操作改名、上色，她当国王，城给她，义军变成守军。
4. 新国和原国**不死不休**：任何途径都议不了和，直到一方灭亡。
5. 原国里和国王不和的领主，有一部分会当场投奔她。
6. 玩家正在资助她（Slot 992 > 0）并且没有效忠任何国家时，弹一个菜单请玩家当封臣。玩家答应就走原版的效忠流程。
7. 新国丢光据点就灭国。空位放回去，她重新流亡，60 天后可以再起兵。

## 第 2 步：攻城与建国（新脚本，追加在末尾）

**Slot**
- 1048（称王者 Troop Slot）：下次可以再攻城的日子。打输了 day+30，灭国后 day+60；0 表示随时。
- 1049（义军部队 Party Slot）：正在去打的据点 +1；0 表示没有目标。

**`af104_pick_siege`（每周，接在 `af63_rebel_one` 第 3 步之后）**
- 条件：`fac_kingdom_7` 是 `sfs_inactive`，义军 ≥150 人，997 ≥3，今天 ≥ 1048。
- 候选：原国的城堡和城镇，距离义军 40 以内，没被围，城主不在城里。守军强度（`party_calculate_strength`）乘城防系数（城堡 ×1.5，城镇 ×2）后要低于义军强度。
- 选得分最高的：守军越弱、越近，分越高。城主怠政（`slot_af08_negligence` ≥60）加分，和 `af65_pick_target` 一样。
- 写 1049，义军改成 `ai_bhvr_travel_to_party` 开往那座城。这一周的「挑软柿子村子」跳过。

**`af104_siege_check`（每 6 小时，挂在 `af65_rebel_evade` 旁边）**
- 1049 有值、义军离目标 ≤2：结算。
- 义军强度 × 随机 80～120% 对比守军强度 × 城防系数。
  - **赢**：义军按守军强度的一半折损（`party_inflict_attrition`）。如果据点已被别人拿走或换了阵营，就作废，只清 1049。然后调用 `af104_found_kingdom`。
  - **输**：义军折损 30%，1048 = day+30，清 1049。
- 第七国已经建立后，后续夺城仍走这一套，只是不再建国，`give_center_to_faction` 直接给第七国。领主有原版 AI 之后，这一套可以停用，由 GPT 定。
- 玩家在附近时只发消息，不拉进战斗（本批不做玩家参战）。

**`af104_found_kingdom`（参数：称王者、据点）**
1. 名字：`faction_set_name` 用 `"@{s10}的王国"`（s10 = 称王者名字）；`faction_set_color` 用第 1 步的颜色。
2. 设 `slot_faction_state = sfs_active`，`slot_faction_leader = 称王者`，`slot_faction_culture` 照抄原国（兵种树不变）。旗帜和形容词（`slot_faction_adjective`）参照原版叛乱成功时的处理（`module_game_menus.py:14332` 一带），没有现成字符串就用 quick string。
3. 称王者：`troop_set_faction` 到第七国，`slot_troop_occupation = slto_kingdom_hero`，`slot_troop_renown` 不低于 1000（照原版），`slot_troop_cur_center = 据点`。
4. 据点：`give_center_to_faction` 给第七国，`give_center_to_lord` 给她。义军的兵**全部并进守军**，然后 `remove_party` 义军，清 993、995、1049。她自己的部队等原版领主刷新去生成，不手工造。
5. **义军相关脚本要跳过她**：`af63_rebel_one` 开头加一条，称王者是第七国国王时直接返回，不然会把「义军不见了」误报成「被打散」。`af65_*` 和 `af63_king_sponsors` 同理。
6. 关系：和原国 `set_relation -40`，走原版开战脚本 `diplomacy_start_war_between_kingdoms`（检查它会不会顺手发通知或改别的国家，必要时只用 `set_relation`）；和其他王国设 0；玩家这边用 `script_set_player_relation_with_faction`，玩家在原国时就是敌对。设完 `$g_recalculate_ais = 1`，再 `update_all_notes`。
7. 领主投奔：原国领主（不是国王）里和国王关系 ≤ -20、和她关系 ≥ 0 的，每人 50% 投奔，最多 3 人，用 `script_change_troop_faction`（看它怎么处理封地，照原版叛变的规矩来）。
8. 通知：全图消息「{s10}夺下了{s11}，自立为王，与{s12}势不两立。」
9. 玩家：她的 992 > 0、玩家不属于任何王国（`$players_kingdom` 是 0 或 `fac_player_faction`）、玩家不是她的敌人时，弹新菜单 `mnu_af104_invite_vassal`。
   - 答应：走原版效忠（`script_player_join_faction` 第七国，看原版宣誓对话要设哪些全局变量）。
   - 婉拒：没有后果。以后也可以照原版去找她对话效忠，要确认原版「请求效忠」对话对 `slto_kingdom_hero` 的她能出来，前面不会被称王者专用对话截走。
10. 资助返还（992）：`af33_settle_pretender` 现在只把「成为原国国王」算登基，要把「成为第七国国王」也算进去，1.5 倍返还走第七国的城镇金库，没有城镇就走她的财产，规矩照旧。

## 第 3 步：不死不休、灭国

**`af104_cf_blood_feud`（参数 A、B）**：A、B 一方是第七国、另一方是她的原国（`slot_troop_original_faction`），并且两国都 `sfs_active` 时，条件成立。

在下面这些地方用它挡住议和：
- `diplomacy_start_peace_between_kingdoms` 开头：成立就什么都不做，直接返回。这是最后一道闸。
- `npc_decision_checklist_peace_or_war`：成立时返回「不议和」（先看它的返回值约定）。
- 玩家看得到的议和入口，**在条件里挡**，不要等扣了钱再挡：`module_dialogs.py` 4811、10545、10630、26961、27667，`module_game_menus.py` 13370、`module_simple_triggers.py` 3869（强制议和），我们的 `af61_find_peace_request`／`af61_broker_peace`（`module_scripts.py:66042`、`66097`），以及 `module_scripts.py:64957`。逐处确认是先扣钱还是先议和。

**`af104_weekly`（每周）**
- 第七国 `sfs_active` 但一个据点都没有，或者原版已经把它设成 `sfs_defeated`（`module_simple_triggers.py:3158` 那段会把它的部队改挂到据点所属阵营）时：
  - 她：`troop_set_faction` 回原来的阵营（建国前先记下，看原版称王者平时属于哪个阵营），`slto_inactive_pretender`，`cur_center = 0`。1048 = day+60，994 也设成 day+60。
  - 第七国剩下的领主：照原版灭国时的处理（看原版有没有自动安置；没有的话改投原国或流浪，GPT 定）。
  - 玩家如果是第七国的封臣：参照原版「效忠的王国灭亡」的处理（`$players_kingdom` 等）。
  - 空位还原：`sfs_inactive`，名字改回 `{!}kingdom_7`，和所有王国关系设 0，清 `slot_faction_leader`、`slot_faction_marshall`。
- 原国被灭：第七国照常存在，以后可以正常和别国议和（`cf_blood_feud` 自然不成立）。

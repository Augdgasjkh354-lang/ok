## 1. 场景

你是斯瓦迪亚封臣。国王这两年把好封地都给了亲信。哈伦、雷玛两位领主封赏一再落空，对国王都有怨气，两人彼此交好。

某天哈伦派信使来：「我们为陛下流过血，好地却都给了身边的人。几位大人已经商量过了，要一起去问陛下，这个王国究竟是谁打下来的。你站哪边？」

你可以：
1. **一起去施压**——哈伦和雷玛记你的好，国王记你的账；
2. **替陛下劝退他们**——国王记你的好，他们觉得你是国王的人；
3. **不掺和**——什么都不变；
4. **先去告诉陛下**——国王抢先压下去；但他们有一半机会知道是你说出去的。

国王按自己的性格和库房回应：
- **出钱安抚**：从国王财产里给每位领主一笔钱，怨气消掉一大截；
- **许诺下次封赏**：国王欠领头的一张封地票（v7.3 的人情债，下次封地议事会核对国王守没守约）；
- **硬顶**：每位领主对国王 −10，怨气再涨。关系一路掉到 −50 时，原版会让他们投奔别国。

## 3. 新脚本（`build/module_scripts.py` 末尾追加）

### 3.1 `af50_is_malcontent`（只读）

- 参数 1：领主；参数 2：阵营。输出 `reg0`：1 是，0 不是。
- 条件：`store_faction_of_troop` = 阵营；`slot_troop_occupation` = `slto_kingdom_hero`；不是国王（`slot_faction_leader`）；没被俘；封地怨气 `slot_fb71_fief_grievance` ≥ 40；对国王关系 < 0。

### 3.2 `af50_find_crisis`（只读）

- 无参数。输出（最后赋值）：`reg0` = 领头的（没有为 -1），`reg1` = 参加的人数（含领头的）。
- 前提：`$player_has_homage` = 1；`$players_kingdom` 在 `npc_kingdoms_begin`～`kingdoms_end`（正常王国；玩家自立的王国不在本批，以后接进政治 2.0 的封臣请愿）。
- 领头的：本国怨气最高的不满者（`af50_is_malcontent` = 1）；对玩家关系 ≥ −10（跟你有深仇的人不会来找你）。
- 参加者：其他不满者里，对领头的关系 ≥ 10 的，最多 3 位（按扫描顺序取前 3 位，保证同一帧里重复调用结果一样）。
- 参加者（含领头的）< 2 → 返回 -1。

### 3.3 `af50_resolve`（写状态，结算）

- 参数 1：玩家立场（1 施压，2 劝退，3 中立，4 告密）。
- 输出（最后赋值）：`reg0` = 国王的回应（1 出钱，2 许诺，3 硬顶），`reg1` = 每人拿到多少（只有出钱时有），`reg2` = 告密有没有被识破（1／0）。结果正文拼进 `s40`。
- 重新调 `af50_find_crisis` 拿领头的和人数；再按 3.2 同样的规则逐个找出参加者（下面「对每位参加者」都这样扫）。领头的 < 0 时什么都不做（`reg0` = 0）。
- **压力**：`压力 = 人数 × 15 + 领头的怨气 ÷ 2`；玩家施压 +20，玩家劝退 −20；告密时压力按 0 算（国王已经有准备）。
- **国王的回应**（`slot_lord_reputation_type`）：
  - 硬脾气（`lrep_martial`、`lrep_quarrelsome`、`lrep_selfrighteous`、`lrep_debauched`）：压力 ≥ 70 才退让，否则硬顶。
  - 其他性格（含 `lrep_none` 等没设的）：压力 ≥ 40 才退让，否则硬顶。
  - 告密：一律硬顶（国王抢先压下去）。
  - 退让时：国王财产 ÷ 4 ≥ 人数 × 1000 → **出钱**，每人 = min(1500, 国王财产 ÷ 4 ÷ 人数)；否则国王对领头的人情债为空（`slot_fb73_debt_to` = 0）时 → **许诺**；两样都不行 → 硬顶。
- **国王的回应落到账上**（对每位参加者）：
  - 出钱：`af14_lord_wealth`（国王, 0, 每人额）、`af14_lord_wealth`（参加者, 每人额, 0）；怨气 −20（最低 0）；参加者↔国王关系 +5。
  - 许诺：国王 `slot_fb73_debt_to` = 领头的，`slot_fb73_debt_since_hour` = `store_current_hours`（v7.3 的人情债：下次本国封地议事时，国王投了领头的 → 守约；没投 → 国王信用 −12、国王↔领头的关系 −8，现成结算）；每位参加者怨气 −10；关系 +2。
  - 硬顶：每位参加者↔国王关系 −10；怨气 +10（最高 100）。
- **玩家立场的后果**：
  - 施压：每位参加者↔玩家 +3；国王↔玩家 −3，硬顶时改为 −6。
  - 劝退：国王↔玩家 +3；每位参加者↔玩家 −3。
  - 中立：不变。
  - 告密：国王↔玩家 +5；然后掷 50%：识破时每位参加者↔玩家 −10、记仇 `slot_fb7_grudge` +10（最高 100），玩家政治信用 −6（`slot_fb73_credit`，先 `fb73_get_credit`，最低 1）。
- 所有关系变化用 `script_troop_change_relation_with_troop`，金额都是原版量级。

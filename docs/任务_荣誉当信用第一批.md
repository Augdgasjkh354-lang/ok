## 0. 场景

分工（以后所有新功能照这张表选数据，不要两个数加成同一件事）：声望＝多少人知道你，荣誉＝**人们信不信你**，威名＝战场上怕不怕你，统治权＝政治上认不认你。本批只用荣誉。

1. **荣誉档**：照 `af20_fame_tier` 的做法，给原版 `$player_honor` 分五档。以后凡是按荣誉判断的功能都调这个脚本，不再直接读 `$player_honor`。
2. **向商会借钱**：在城镇的「经商赚钱」子菜单里，可以向本城商会借一笔钱，30 天内连本带息还清。荣誉越高，借得越多、利息越低；名声坏了（荣誉 < 0）商会不借。按时还清，荣誉 +1；逾期了，荣誉和城镇关系逐周往下掉。
3. **借兵看荣誉**：向领主借兵（L1）的好感门槛按荣誉档调；借兵逾期 7 天被强制收回时，荣誉 −2。

**钱的流向**（本批只有这两笔，都是真实转账）：
- 借钱：城镇金库 `slot_town_wealth` → 玩家金币。一次最多出金库的 **1/4**（借钱是玩家主动要的，不是城镇欠玩家的，所以照「往外拿钱一次最多 1/4」，不走 3/4 那条，也不让城主、国王补）。
- 还钱：玩家金币 → 同一座城的金库，本金＋利息全额。利息就是这座城的进账。
- 不还：钱已经在玩家手里，账上记着欠，不凭空生灭；代价是荣誉和关系。

**防套利**：最低利率 5%／30 天，高于钱庄的 1%／周（约 4.3%／30 天），借商会的钱再放进自己的钱庄是亏的。

## 2. 新脚本（`build/module_scripts.py`，追加在 `scripts` 列表末尾）

### 2.1 `af68_honor_tier`（只读，不带参数）

只读 `$player_honor`，输出 `reg0`：

| reg0 | 荣誉 | 名称（给 2.2 用） |
|---|---|---|
| 0 | < 0 | 失信 |
| 1 | 0～9 | 平常 |
| 2 | 10～29 | 守信 |
| 3 | 30～59 | 重诺 |
| 4 | ≥ 60 | 一诺千金 |

写法照 `af20_fame_tier`（`build/module_scripts.py:58435`）的 `try_begin / else_try` 链。门槛 10 与 `af20_fame_kind` 的仁名门槛一致，不要改。

### 2.2 `af68_loan_offer`（只读，参数 1：城镇）

算出这座城现在肯借多少、利率多少。输出 `reg0`＝可借金额（0 表示不借），`reg1`＝利率（百分数），`reg2`＝荣誉档。**三个输出寄存器都在脚本最后赋值。**

1. 调 `af68_honor_tier` 得 `:tier`（马上存进局部变量）。
2. 按档取上限 `:cap` 和利率 `:rate`：

   | 档 | 上限 | 利率 |
   |---|---|---|
   | 0 | 0（不借） | — |
   | 1 | 1000 | 20 |
   | 2 | 3000 | 15 |
   | 3 | 6000 | 10 |
   | 4 | 10000 | 5 |

3. 读金库 `slot_town_wealth`，`val_max 0`，除以 4 得 `:limit`；`:cap` 取 `val_min :limit`；再整到百位（`val_div 100`、`val_mul 100`）。
4. 下面任意一条成立，`:cap` = 0：
   - 玩家和这座城的关系 `slot_center_player_relation` < 0；
   - 原版商会欠债 `$debt_to_merchants_guild` ≥ 50（原版商会不跟欠债的人打交道，我们也一样）；
   - `:cap` < 500（金库太穷，借不动）。
5. 最后赋值：`reg0 = :cap`，`reg1 = :rate`，`reg2 = :tier`。

### 2.3 `af68_loan_take`（写状态，参数 1：城镇，参数 2：金额）

- 开头再算一次：调 `af68_loan_offer`，参数 2 > `reg0` 或 `reg0` = 0 就什么都不做，`reg0 = 0` 返回（菜单打开以后金库可能已经变了）。
- 否则：
  1. `:owed = 金额 × (100 + 利率) / 100`；
  2. 金库减金额（`party_get_slot` → `val_sub` → `party_set_slot`，照钱庄的写法），`troop_add_gold` 玩家加金额；
  3. 1003 = 城镇，1004 = `:owed`，1005 = 今天 + 30。
- 输出 `reg0 = 金额`，`reg1 = :owed`（最后赋值）。

### 2.4 `af68_loan_repay`（写状态，参数 1：城镇）

- 条件：1003 = 参数城镇，玩家金币 ≥ 1004。不满足就 `reg0 = 0` 返回，什么都不扣。
- 先把 `:owed`、`:due` 读进局部变量，`:today` = `store_current_day`。
- 玩家扣 `:owed`，金库加 `:owed`。
- 按时（`:today ≤ :due`）并且借满 7 天（`:due − :today ≤ 23`）：荣誉 +1（`script_change_player_honor`），城镇关系 +1（`script_change_player_relation_with_center`），冷却 1005 = 今天 + 7，`:kind = 1`。
- 按时但不满 7 天：不加荣誉、不加关系（防止借了马上还来刷荣誉），冷却 = 今天 + 7，`:kind = 2`。
- 逾期：不加不减（逾期的代价已经由第 4 部分逐周扣过），冷却 = 今天 + 30，`:kind = 3`。
- 清 1003、1004 为 0。
- 最后赋值：`reg0 = :kind`，`reg1 = :owed`。中途调的荣誉、关系脚本会改写寄存器，所以一定要放最后。

## 3. 菜单（`build/module_game_menus.py`，`mnu_af34_trade`）

### 3.1 子菜单里的两个选项

插在 `af30_tax_farm_entry` **之后**、`af34_trade_back`（「返回城镇」）之前：

**`af68_loan_borrow`**：借钱
- 条件：
  1. `(is_between, "$current_town", towns_begin, towns_end)`；
  2. 1003 = 0（手上没有贷款，哪座城的都不行）；
  3. 1005 ≤ 今天（冷却过了；0 也算过了）；
  4. `af68_loan_offer "$current_town"` 的 `reg0` > 0；
  5. 把要显示的数存进 `reg41`（金额）、`reg42`（利率）、`reg43`（30 天后要还的总数）。**放在条件最后**，调完脚本再赋值。
- 文本：`向本城商会借 {reg41} 第纳尔（30 天内还 {reg43}，利息 {reg42}%）`
- 后果：`af68_loan_take "$current_town" 金额`（金额重新调 `af68_loan_offer` 取，不要用 reg41，后果里的寄存器不可靠）。`reg0` > 0 时提示 `@商会借给你 {reg0} 第纳尔，三十天内还 {reg1}。` 否则提示 `@商会的账房摇了摇头：今天借不出这么多了。`；最后 `jump_to_menu "mnu_af34_trade"`。

**`af68_loan_repay_entry`**：还钱
- 条件：1003 = `$current_town`，玩家金币 ≥ 1004；`reg41` = 1004（最后赋值）。
- 文本：`还清商会的借款（{reg41} 第纳尔）`
- 后果：调 `af68_loan_repay "$current_town"`，按 `reg0` 提示：
  - 1：`@账结清了。商会的人说，你是个讲信用的人。`
  - 2：`@账结清了。`
  - 3：`@账结清了，可账房记下了你拖欠的日子。`
  - 然后 `jump_to_menu "mnu_af34_trade"`。

只做一次还清，不做分期还款。借钱的选项一个就够，不做「借一半」。

## 4. 逾期（`build/module_simple_triggers.py`，追加在文件末尾）

一个 `(24, [...])` 触发器：

1. 1003 > 0，`:today` > 1005，`:late = :today − 1005`；
2. 城镇所属阵营和 `fac_player_faction` 正在打仗（`store_relation` < 0）时，这一天不罚，直接结束（打仗的时候回不去，商会认这个理）；
3. `:late` = 1：荣誉 −3，该城关系 −5，提示 `@{s4}商会的借款到期了，你还没还。消息传得很快。`（`s4` = 城镇名，**在调荣誉、关系脚本之后再取**）；
4. `:late` = 8、15、22、29：荣誉 −1，该城关系 −2，提示 `@{s4}商会又派人来催债了。`；
5. 其余日子什么都不做。逾期 29 天之后不再罚，但账一直挂着，直到还清；手上有这笔账就不能再借（3.1 条件 2）。

最多合计荣誉 −7、关系 −13。数值和原版量级对齐（原版背约 −5 左右）。只用逾期天数判断是哪一天，不另开计数 Slot。

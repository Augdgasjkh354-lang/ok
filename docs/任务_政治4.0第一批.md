## 0. 为什么这样做

现有的两种停战都是一次了结：I4 外交掮客（两国各付玩家 2000，`lord_af26_mediate`）、资本家 2.0 出钱买和平（玩家掏 5000，`af33_buy_peace`）。本批加第三种：**强国答应停战，弱国分期赔款**。赔款分四周付，付不起就违约，违约给对方留下宣战理由。

**停战本身不另造**：沿用原版 `diplomacy_start_peace_between_kingdoms`（`build/module_scripts.py` 约 25550 行），它会设 40 天停战、交换俘虏、解除围城。

**违约的后果用原版的宣战理由（casus belli）**：原版劫掠、袭击商队时，会给被害国记 30 天的「宣战理由」（阵营 Slot `slot_faction_provocation_days_with_factions_begin` + 对方阵营 − `kingdoms_begin`，见约 25383 行的写法），AI 决定宣战时会参考它。本批违约时照同一写法给收款国记 30 天，**不直接改两国关系、不直接宣战**（`set_relation` 设成负数就等于开战，绝对不要碰）。

## 1. 场景

斯瓦迪亚和罗多克打了很久，斯瓦迪亚占优（城多）。你跟两国国王都有交情。

- 你找斯瓦迪亚国王 →「聊聊宫廷里的事」→「陛下，罗多克撑不住了。我去谈：停战，罗多克赔 6000 第纳尔，分四周付清。」
- 两国当场停战（原版 40 天停战）。斯瓦迪亚国王对你 +3，罗多克国王 +1。
- 之后每周，罗多克国王从自己的财产里拿出 1500 付给斯瓦迪亚国王。
- 罗多克国王某周拿不出来（一次最多动财产的 1/4）：只付得起多少付多少，差的继续欠着；斯瓦迪亚国王对罗多克国王 −5，斯瓦迪亚拿到 30 天宣战理由。停战期一过，斯瓦迪亚可能就打回来——下一场战争的种子，就埋在上一场的赔款里。
- 四周付清：两国国王关系 +3，条约结束。
- 两国中途又开战了：条约作废，没付的不再付。

**钱的流向**：欠款国国王财产 → 收款国国王财产（`af14_lord_wealth` 一减一加）。玩家一文不出、一文不拿（好处是两位国王的交情）。

## 3. 新脚本（`build/module_scripts.py` 末尾追加）

### 3.1 `af53_treaty_target`（只读）

- 无参数，读 `$g_talk_troop_faction`（对话中的国王的国家，记作 A）。输出（最后赋值）：`reg0` = 1 找到／0 没找到，`reg1` = 弱国 B，`s4` = B 的国名。
- 照 `af33_buy_peace_target` 的写法，但**方向相反**：找与 A 交战、且 **B 的据点比 A 少**（A 是强势一方）的 B。
- 另加条件：B 的国王是 NPC（`active_npcs_begin`～`active_npcs_end`）、玩家对 B 国王关系 ≥ 20；B 身上没有生效的条约（`slot_af53_reparation_left` = 0）；B 在 `npc_kingdoms_begin`～`kingdoms_end`（不对玩家自立的王国用）。
- 多场战争时取扫描到的第一个（用 `(eq, reg0, 0)` 守循环，照原写法）。

### 3.2 `af53_sign_treaty`（写状态）

- 参数 1：A（强国），参数 2：B（弱国）。输出 `reg0`：1 签成，0 没签（条件变了）。
- 重查：两国仍在交战（`store_relation` < 0）；B 的 `slot_af53_reparation_left` = 0。
- 签成：
  - `diplomacy_start_peace_between_kingdoms`（A, B, 1）；
  - B 的 `slot_af53_reparation_to` = A，`slot_af53_reparation_left` = 6000；
  - `change_player_relation_with_troop`（A 国王, 3）、（B 国王, 1）。

### 3.3 `af53_weekly_reparations`（写状态，每周结算）

- 无参数。`try_for_range` `npc_kingdoms_begin`～`kingdoms_end`，对每个 B：
  - `slot_af53_reparation_left` ≤ 0 → 跳过（这一国没有条约）。**这一条和下面每个分支都包在各自的 `try_begin` 里**，一国不满足不能把后面的国连带跳过。
  - 取 A = `slot_af53_reparation_to`；两国国王 `slot_faction_leader`。
  - **作废**：A 或 B 已经不在（`slot_faction_state` ≠ `sfs_active`），或任一国王不是 NPC 领主，或两国又在交战（`store_relation` < 0）→ 两个 Slot 清零；两国中有一国是 `$players_kingdom` 时消息「{B}与{A}之间的赔款条约作废了。」
  - **付款**：本周应付 = min(1500, 还欠)；实付 = min(应付, B 国王财产 ÷ 4)。`af14_lord_wealth`（B 国王, 0, 实付）、`af14_lord_wealth`（A 国王, 实付, 0）；还欠 −= 实付。
  - **违约**（实付 < 应付）：`script_troop_change_relation_with_troop`（A 国王, B 国王, −5）；A 对 B 的宣战理由：`store_add, ":slot", B, slot_faction_provocation_days_with_factions_begin`、`val_sub, ":slot", kingdoms_begin`，`A` 的该 Slot 为 0 时设成 30（照原版 25383 行，不覆盖已有的）。消息「{B}没能按期付清赔款，{A}记下了这笔账。」（**所有国家都发**：违约是会引起战争的大事，玩家又是牵线人。）
  - **付清**（还欠 = 0）：两个 Slot 清零；两国国王关系 +3；消息「{B}付清了给{A}的赔款。」
  - 其他情况：写回还欠的数。
- 输出：无。消息里的国名用 `str_store_faction_name` 存 `s10`／`s11`，**在调完所有会改 `s` 寄存器的原版脚本之后**再存、再 `display_message`。

## 4. 对话（`build/module_dialogs.py` 末尾追加，`lord_talk_court` 下的玩家选项）

条件（照 I4）：
1. 对方是本国或他国的**国王**（`faction_slot_eq, "$g_talk_troop_faction", slot_faction_leader, "$g_talk_troop"`）；
2. 玩家声望 `slot_troop_renown` ≥ 200；
3. 玩家与对方关系 ≥ 20；
4. `af53_treaty_target` 的 `reg0` = 1。

文字：「陛下，{s4}撑不住了。我去谈：停战，{s4}赔 6000 第纳尔，分四周付清。」
后果：重新调 `af53_treaty_target` 拿 B，`af53_sign_treaty`（`$g_talk_troop_faction`, B），结果存 `$temp`；重存 `s4`（B）、`s5`（A）。去向 `af53_treaty_reply`。

回应（都回 `lord_talk_court`）：
- `$temp` = 1：「好。{s4}肯认这笔账，这仗就先停下。四周之内，一个子儿也不能少。」
- 其他：「这事已经变了，再说吧。」

中性称呼，不用「他」。

注意：`lord_talk_court` 只在跟领主／国王说话时进得去（第一层「聊聊宫廷里的事。」）；外国国王也能进，这是要的（你可以替外国国王去压它的敌人）。

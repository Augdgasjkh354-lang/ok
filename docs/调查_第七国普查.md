# 调查：第七国普查（称王者夺城建国 第 4 步）

2026-11-18，Claude 做。目的：`fac_kingdom_7` 落在王国区间（`kingdoms_begin..kingdoms_end`）里以后，原版和我们自己的代码有哪些地方会出问题。规格见 `docs/任务_称王者建国.md`。

## 结论先说

- **空位期间最大的风险**是原版的 `slot_faction_leader` 默认值 0，而 0 是玩家，第七国会被当成「玩家当国王的国家」。开局时已经把它设成 -1，状态设成 `sfs_inactive`。
- 王国之间的战和、亡国、找新东家、停战倒计时，原版都先检查 `sfs_active`，空位不会被卷进去。
- **按国家编号取数组下标**的地方会越界：头衔字符串、六国匪帮、快速战斗和多人的阵营列表。都已处理，见下表。

## 看过、不用改

- 52 处「按王国循环、但没检查是否活着」的地方：多数只是改关系、清临时值、查有没有交战（空位和谁的关系都是 0）、按阵营找部队或据点（空位没有）。
- 停战天数、挑衅天数、战争损伤这些槽位按 `阵营号 - 14` 或 `阵营号 + 140` 算，第七国落在空闲槽位里（127、137、161），不撞。据点上「最后侦察时间」落在 357，也是空的。
- 战和通知的双旗帜图是按国王的个人旗帜画的，第七国国王（称王者）有自己的旗帜，能正常显示。
- `triggers.txt` 是跟着对话一起重新编译的（`process_dialogs.py`），不是沿用 v0.8，所以里面 5 处王国循环也包含第七国。规格里「不包含」的说法是错的，已更正。
- 原版「效忠」对话对已经是 `slto_kingdom_hero` 的称王者走的是普通国王流程（称王者专用对话都检查了「不是国王」），以后可以去找她当面宣誓。

## 留着没改（影响小，待实机看）

- `module_scripts.py` 里按阵营起口语称呼的地方（「斯瓦迪亚人」之类，`s39`）：第七国没有这一档，会沿用前面填的字符串。
- 按阵营挑音乐文化、按阵营挑逃兵兵种（`af02` 逃兵）：第七国走默认值（音乐默认、逃兵默认斯瓦迪亚步兵）。
- 原版任务「说服领主议和」可能挑到血仇一对：任务能做，但议和那一步被闸住，不会真的停战。
- 称王者专用的叛乱台词按 `阵营号 - 1` 取字符串：只在玩家照原版扶称王者、对方国王是原国国王时出现，原国只会是六国之一，用不到第七国。

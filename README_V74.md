# FewerBandits v7.4 — 宫廷暗战

**游戏版本**：《骑马与砍杀：战团》1.174，基线 v7.3；本版为增量升级。

## 新功能

1. **政治嫌疑**：AI 私下拉票、玩家买票、互惠承诺和收买倒戈都会积累独立的政治嫌疑（0–100）。嫌疑会随时间消退，不会永久持续。
2. **政治情报与泄露**：玩家和同国贵族交谈可以打听最近的秘密交易传闻。领主只会透露真正存在嫌疑的其他贵族，并提供可保存的线索强度。线索在 14 天后失效，同一位传闻提供者有 3 天冷却。
3. **国王调查与惩罚**：当领主或玩家嫌疑足够高，王室可能主动识破秘密交易。查出后涉事者与国王关系 -8、政治信用 -6；NPC 领主额外增加争议度（+12），削弱派系忠诚；曝光次数会保存在存档中，同一人的调查有 7 天冷却。
4. **玩家向国王举报**：玩家与自己效忠的国王交谈，可以提交最近收集的同阵营情报。举报成功后，涉事领主承担调查后果，玩家与国王关系 +3；线索随后被消耗，不能无限重复举报。
5. **派系倒戈**：同一王国内，不满现派系的普通成员可能转入另一支已有的秘密派系；不允许跨国挖角，不移动派系领袖，且新派系成员上限仍为 4 人。改变阵营后更新成员关系、派系忠诚与候选人缓存，真实改变后续派系投票和援护。
6. **玩家收买倒戈**：和合适的同阵营领主私人会谈，可看到潜在的对立派系领袖，出资约 7000–26000 第纳尔收买。接受才付款；成功后该领主会欠玩家一次将来的封地支持。拒绝不会扣钱，但会留下少量嫌疑。领主主动倒戈有 21 天冷却，且不能带着旧承诺或人情债直接脱身。
7. **中文对话及消息**：新增 9 条中文对话，包含游说倒戈、打听传闻和向国王提交线索；王室调查消息已中文化。

## 与旧版兼容

- v7–v7.3 的恩怨记忆、政治派系、封地野心、私下交易、政治信用及普通/满级开局保留。
- v7.4 只追加领主槽位 **631–640**、**5 个**全局变量、一个新的字符串 ID、9 条对话和一个每日触发器；原有变量、兵种、物品、地图、开局菜单与其他旧文本索引保留。
- 新版 v7.4 源码可复现游戏数据；旧存档新增槽位初值为 0。建议测试时另存新档。
- 没有加入真正的国王废黜、叛军组建、玩家直接担任秘密派系领袖或独立情报网络；这些属于未来版本。
- **静态编译与包校验通过，尚未进行游戏客户端实测。**

## 安装

1. 备份 `MountBlade Warband/Modules/TestMod/` 和游戏存档。
2. 解压安装包，将 **FewerBandits 文件夹内部**的全部文件覆盖到 `Modules/TestMod/`。不要删除 `TestMod` 下已有的 `map.txt`、`module.ini`、`SceneObj` 等文件。
3. 建议新存档优先确认 v7.3 的政治交易和满级开局依然可用，再等待出现王国封地议程测试新的政治机制。

## 实测清单

- 在封地议事期间买票/互惠，多日后打听传闻；确认 3 天冷却和 14 天情报时效。
- 向本国国王举报线索，看涉事者是否受到处罚，举报者与国王关系是否提升，线索是否被消耗。
- 观察有派系的同阵营领主是否出现“收买转投另一派系”提议，并核对实际扣款、派系归属、后续封地票。
- 若拒绝收买则不扣款；领主已有未履行交易/人情债时不得无视旧债倒戈；被俘领主无法倒戈。
- 复查原有元帅选举、政治投票、开局满级属性、同伴和六种雇佣兵。

# FewerBandits v7.5 — 宫廷政治收尾版

基线：《骑马与砍杀：战团》1.174 / FewerBandits v7.4；不修改地图、兵种、物品或原版战斗。

## 本次已实现

1. **营地 → 宫廷政治情报簿**（无需作弊模式）：查看玩家政治信用、嫌疑、被调查次数、有效情报数、应收及应付的未来投票债。可逐条浏览有效线索（可信度、剩余有效天数）及欠玩家选票的贵族。只展示玩家已获取的线索，不展示未掌握的秘密。
2. **传闻冷却反馈**：同一贵族三天内不重复提供新传闻；冷却期间明确说明还剩多少天，解决“没有传闻”和“询问太频繁”混淆。新增 `slot_fb75_last_rumor_token=641`，以「当前天+1」表示最近查询天，避免游戏第 0 天绕开冷却；仍兼容旧版 `slot_fb74_last_rumor_day=640`。原有 14 天后过期的举报规则不变。
3. **营地 → 作弊菜单 → 宫廷政治测试（v7.5）**：玩家嫌疑 +60、生成一条可以提交给国王的测试线索、手动运行一次王室政治检查、尝试一次符合现有规则的派系转投。该入口只应在测试存档中使用；测试行为会写入存档。
4. **稳定性与重编译**：原有脚本 ID 及菜单 ID 保留，7.4 的 1272 个全局变量顺序保持不变，仅追加 `g_fb75_gossip_wait`、`g_fb75_view_lord` 两个新变量。旧 Slot 600–640 未更换含义。
5. **中文本地化**：新游戏菜单中文显示，冷却对话已中文化；历史 v7–v7.4 对话中文继续保留。

## 安装

1. 先备份 `MountBlade Warband/Modules/TestMod/` 整个目录及存档。
2. 这是 **v7.4 → v7.5 增量升级包**，须先安装 v7.4（安装包不含 `module.ini`、`map.txt`、`SceneObj`）。
3. 解压 `FewerBandits-v7.5-游戏增量包.zip`，把 `FewerBandits/` **内部的六个 `.txt` 文件**覆盖到 `Modules/TestMod/` 目录，不要将文件复制到另一个多余的嵌套目录。
4. 旧存档可保留载入并另存副本；新功能的状态由追加变量和 Slot 维护。尚未在 Windows 游戏客户端中验证旧存档兼容性。
5. 进入游戏，扎营选择「宫廷政治情报簿」查看信息；开启作弊模式后，可在营地作弊菜单测试政治逻辑。

## 源码与构建

- **权威源码**在 `build/module_*.py`；`sources/` 保存旧版本历史快照，不可替代当前代码。
- 运行 `python build_v75.py`：从 `baseline/v74/compiled/` 中的原版 v7.4 编译基线恢复，再重编译 v7.5 改动所依赖的文件、套用历史中文本地化，输出 `game-data/`。Python 3 环境即可。
- `python build_v75_fast.py`：与上面相同的推荐增量构建。
- `python build_v75_full.py`：如今后修改了其他原版源码模块，可选择完整重编译，耗时明显更长。它使用同样的变量前缀保护及本地化收尾。
- `python scripts/verify_fb_v75.py`：检查 v7.4 全局变量和已有 ID 未发生位移、打包变化范围、主要新增代码存在、中文文字已生成。

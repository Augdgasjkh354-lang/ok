# 《卡拉迪亚：烽烟与暗流》v0.2 — 流民与逃兵

**状态**：完成源代码、Module System 编译、静态兼容审计及重复构建。尚未执行《战团》客户端实测（留待后续）。

## 基础和目标

* **必须基于 v0.1**（该版已包含 FewerBandits v7.5 的全部政治系统）。
* v0.2 沿用 v0.1 唯一新增的“战乱度”，不引入独立民心；村庄关系与繁荣度继续调用原版系统。
* 增加两类世界地图动态部队：从动乱村庄逃出的流民，以及在当地游荡的逃兵；玩家可互动。

## 事件规则（首版平衡值）

| 行为 | 规则 |
|---|---|
| 流民生成 | 最近 21 天遭洗劫，村庄战乱度 ≥40，当前未正在遭劫；每天每村 20% 生成机会，成功生成后 6 天冷却 |
| 流民上限 | 世界地图上最多 **10** 支，通常每村最多 1 支（特殊作弊菜单可手动额外生成） |
| 目的地 | 优先选择**同阵营且未被围攻**的最近城镇；没有时选择可通行、非敌对城镇 |
| 流民抵达 | 目的地繁荣度 +1，故乡战乱度 -4；队伍消失 |
| 流民过期 | 出生 20 天后仍未抵达则消失，不发抵达奖励 |
| 给予路费 | 玩家支付 150 第纳尔，故乡战乱度 -2、村庄关系 +1；每支流民只能领取一次 |
| 接纳流民 | 玩家至少 6 个队伍空位，流民队伍至少还有 6 人；加入 4 农民、2 农妇，故乡战乱度 -1，流民队伍消失 |
| 逃兵生成 | 最近 21 天遭洗劫，村庄战乱度 ≥65，未正在遭劫；每天每村 13% 机会，成功生成后 9 天冷却 |
| 逃兵部队 | 原村庄的初始王国决定兵种，12–23 名士兵；在原村庄附近巡游；生成时故乡战乱度 +3 |
| 逃兵上限 | 世界地图最多 **7** 支；每村最多 1 支；16 天后过期消散 |
| 招安逃兵 | 统御 ≥2，至少 6 个空位和 600 第纳尔，逃兵还有至少 6 人；招入 6 名原籍士兵，故乡战乱度 -6 |
| 收买遣散 | 支付 250 第纳尔，逃兵队伍解散，故乡战乱度 -2 |
| 武力处理 | 使用原版野战系统，玩家可直接攻击逃兵；本版没有额外的战后治安奖励钩子 |

> 设计考虑：v0.1 单次普通劫掠造成 8+35=43 点战乱，所以流民生成阈值设为 40，确保一次严重劫掠就有机会引发流民；逃兵需要更严重或持续的战乱。

## 游戏入口

* 世界地图上：**来自某村的流民**向安全城镇移动；主动接触后会打开流民交互菜单。
* 世界地图上：**来自某村的逃兵**会在原村附近巡游。遇到时出现招安、收买、作战选项。若逃兵主动截击玩家，不能直接无代价离开。
* 村庄 → 原有「查看地方战乱与援助」：额外显示以该村为来源的**当前流民与逃兵队伍数**。
* 营地 → 原有 v0.1 作弊测试菜单：新增流民与逃兵强制生成调试项（遵循地图总量上限，但跳过随机和自然冷却）。

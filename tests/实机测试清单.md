# Ashfall v0.1 实机验收清单（尚未执行）

## 基本功能

- [ ] v7.5 新存档及原有旧存档均能启动，政治情报簿、政治举报、投票、债务仍正常。
- [ ] 正常村庄最初战乱 0；处于 looted 的旧存档村庄首次读取为战乱 43，原有繁荣度不再次降低。
- [ ] 任意村庄菜单出现「查看地方战乱与援助」；状态、关系、繁荣、近期事件与冷却文字正确。
- [ ] 手动洗劫：进入 being_raided +8，完全 looted +35；同日反复进入同一状态不会重复加入战乱。
- [ ] AI 洗劫：同样触发完整流程；同阵营、距离 < 13 的邻村 +6，非同阵营或远离的村庄不受影响。
- [ ] 洗劫后 7 天内战乱不自然恢复；超过 7 天在战争中每天 -1，和平时期每天 -2；连续 120 游戏日无溢出。
- [ ] 城堡归属变化使村庄阵营变化时增加 12 战乱；同一阵营不反复加值。

## 三项援助（必须用独立测试村庄检查）

- [ ] 战乱不足 20 无法援助；敌方、正在遭洗劫、被土匪占据村庄无法援助；looted 仅能救济。
- [ ] 600 第纳尔救济：立即只扣一次，次日战乱 -3、关系 +4、繁荣 +2。
- [ ] 200 第纳尔巡防：至少 20 人；立即只扣一次，次日战乱 -12、关系 +1。
- [ ] 2 谷物赈灾：物品栏不足时明确报错，满足条件则立即扣 2 件，次日战乱 -5、关系 +2、繁荣 +3。
- [ ] 同一村庄当日重复进入菜单不能再次领取奖励；冷却 7 天整可再援助；存档再加载后状态无重复扣费、无重复结算。
- [ ] 援助次日叠加当日自然战乱衰减时，界面显示的总变化符合预期。

## 招募与回归

- [ ] 战乱 < 40 时原版村庄征募未改；战乱 40–69 乘 90%；战乱 ≥ 70 乘 75%。
- [ ] 原版村庄关系对征兵门槛和质量的影响不变，NPC 补兵仍正常。
- [ ] 营地作弊菜单测试入口可用，所有调试操作只影响被选择的最近村庄（洗劫模拟允许同阵营近邻受影响）。
- [ ] 30/60/120 天时间线下没有持续刷屏、死循环、异常政治结果或未解决的游戏运行错误。

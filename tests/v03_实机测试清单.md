# Ashfall v0.3 — 后续统一实机测试清单（当前未执行）

## 安装兼容
- [ ] 从 v0.2 模组备份后覆盖六个新数据文件，旧存档能载入、保存且不丢失 v7.5 的政治情报簿与 v0.1/v0.2 功能。
- [ ] 城镇新增「战争承包商·军粮委托」，营地新增「军事委托记录」，英文／中文菜单不会报错乱码。
- [ ] 无战争时城市不会无故提供护送／截粮任务。
- [ ] 源码作弊菜单可手工发车以快速测试。

## 护送
- [ ] 交战王国的未被围城镇有路线时，15 人及以上队伍可领护送。
- [ ] 真实军粮队出现在出发城镇，路线和阵营正确、地图上能正常移动。
- [ ] 玩家连续靠近军粮队，每 6 小时护送检查+1；长时间离开会逐步衰减。
- [ ] 玩家靠近目标城镇且符合护送检查时，完成任务，目标城市繁荣 +2。
- [ ] 玩家远离目标城镇时无法冒领；军粮队被消灭、城市易主或过期时不能冒领奖励。
- [ ] 返回签约城镇后，发放准确第纳尔及 2 点声望；重复进入菜单不重复领奖。

## 截粮
- [ ] 存在交战敌国路线时可以接任务；敌方运输队是实际地图部队、标有敌国阵营。
- [ ] 玩家亲自战斗获胜可触发合同成功；敌军目的地繁荣 -2 且只结算一次。
- [ ] 由 AI 消灭敌军目标时合同失败，不会假冒玩家获胜。
- [ ] 战败、撤退、目标抵达目的地、期限届满时不会发放成功报酬。
- [ ] 攻击非敌对阵营遵循原版外交行为，不致引起异常脚本错误。

## 长期
- [ ] 交战王国地图上自动出现军粮队；总量不超过 8，单国同一时间至多 1 支。
- [ ] 连续运行 90–120 游戏日后，军粮队均会抵达／消散，没有残留任务或无限增殖。
- [ ] 合同停滞时可随时在营地注销，无永久锁死。

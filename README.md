# 卡拉迪亚：烽烟与暗流 (Ashfall)

《骑马与砍杀：战团》（Mount & Blade: Warband）原版增强 Mod，继承 FewerBandits v7.5。

## 当前进度

- 最新源码开发版本：**v0.9「路上的旧人」**
- 已进行 Module System 编译、静态编号与汉化键检查
- Windows 客户端运行、旧存档加载及实际中文显示尚待实测
- 已开发的机制：贵族政治、村庄战乱、难民与逃兵、军事运输、匪帮、围城及战后治理、AI 领主巡防、地方传闻、旧人重逢

## 本仓库同步状态

当前已经上传项目的开发规范、中文编译指南。

**v0.9 完整源码与游戏安装包暂未上传至 GitHub。** 本仓库目前还不能直接执行 Mod 构建，请勿误认作完整发布版本。

- [AGENTS.md](AGENTS.md)

## 项目原则

优先提升原版卡拉迪亚的游玩体验，让 NPC 有动机、世界有后果、选择有回响；保留旧存档编号与汉化译名，避免堆砌重复属性和无意义事件。

# FewerBandits v7.3 — 权力的暗流

基线：v7.2，目标：《骑马与砍杀：战团》1.174（Module System 1.171，Python 3 兼容编译）。

## 新功能

1. **AI 领主秘密游说**：当王国正在讨论封地赏赐时，有封地野心的领主会私下接触不同派系的贵族，争取一张支持票。游说成功后，对方会在本轮投票支持发起者。成功拉票会留下可在下轮兑现的互惠人情债；七天内不会重复无节制地游说。
2. **玩家金钱换票**：面对同阵营领主，可以选择私下会谈，以 3500–12000 第纳尔的动态报价尝试争取其在当前封地议事中的一票。报价依关系与玩家政治信用计算，领主可拒绝；仅成交才扣钱。若已付款领主在投票前失信，结算或议程取消时退还款项。
3. **玩家互相支持**：在同阵营封地议事期间，玩家可立即投票支持一位相熟领主，换取其下一次封地议事支持玩家的一张人情债。签约时会直接把玩家当前票投给该领主；只有最终投票守约，人情债才成立。同一位领主一次只背负一个可追踪的未来人情债。
4. **政治信用**：玩家及领主的政治信用默认 50，范围 1–100；兑现承诺增加信用，失信降低信用并记录次数。玩家可在密谈中主动毁约，触发信用 -18、关系 -15、个人仇恨 +15；AI 在关系严重恶化时也可能改变立场，投票结算后承受失信后果。
5. **票据清算与时效**：承诺以封地编号及当前议程开始时间双重绑定。发放封地时，系统依据真正的投票结果结算承诺与欠票；新议程不会继承旧议程的一次性交易。互惠支持优先于 v7.2 派系集体候选人，元帅选举不受影响。
6. **中文私人会谈**：向领主提出私下政治交易，可选择金钱换票、互惠换票、主动毁约、查看人情债与政治信用；新增 15 条中文对话。

## 保留内容

v7 恩怨记忆与复仇、v7.1 私盟与庇护、普通/满级开局、v7.2 封地野心和派系集体推举全部保留。原有兵种、装备、酒馆同伴和脸包资源不变。

## 机制边界

- 交易只影响**当前正常的王国封地议事投票**；国王有权按原版逻辑推翻票选结果。政治信用不是玩家声望，也不会自动触发改朝换代。
- 没有加入政治丑闻公开曝光、国王惩罚、军援交易、跨王国外交或实际政变；这些属于后续版本。
- 当封地议程被撤销，未履行的一次性交易作废，玩家已付买票款项返还。交易将来是否兑现取决于新议程、阵营是否相同和实际投票。
- v7.3 代码编译与数据差异检查已经通过，尚未在本环境启动《战团》进行实机测试。

## 安装和测试

1. 备份游戏存档和 `MountBlade Warband\Modules\TestMod`。
2. 解压 `FewerBandits-v7.3.zip`，将 `FewerBandits/` **里面的文件**覆盖到 `Modules\TestMod/`。不要重命名 `TestMod`，保留既有 `map.txt`、`module.ini` 和 `SceneObj`。
3. 可用 v7.2 存档继续测试，新槽位在首次访问时按空记录/政治信用 50 初始化；建议另存新档后进行政治交易。为检验 AI，自行等待出现封地议程，再交谈并观察领主投票。
4. 用同阵营两位领主测试：支付并接受后核对金钱及投票；提出互惠后核对玩家已投票、结果公布后的人情债；下一次正常封地议事再验证兑现。再测试主动毁约、信用扣减和恩怨变化。
5. 复查满级开局（62级/属性63/技能10/熟练度699）、元帅投票、六种特殊雇佣兵、酒馆同伴及其他既有功能。

## 技术和版本审计

- 新领主槽位 620–630；原有 600–619 均保留。玩家 0 号兵种使用专用 -2 保存标记，避免和空槽位 0 混淆。
- 原有全局变量序号严格保留，新增 4 个全局变量只追加在末尾；旧兵种、物品和阵营编号未变。
- 新增 10 个脚本、1 个每日触发器及 15 条对话；原封地议程结算加入一次交易账本清算。
- 完整通过 Module System 编译、历史中文保留、编译差异审计、ZIP CRC 校验；没有开展实际游戏内测试。

# 《卡拉迪亚：烽烟与暗流》v0.5 — 宫廷政治与战争联动

**项目状态**：已完成 Module System 源码与编译、静态编号审计和可复现构建；尚未在《骑马与砍杀：战团》Windows 客户端进行实机测试。

## 基线和升级路径

- 继承 FewerBandits v7.5 政治系统，以及《烽烟与暗流》v0.1–v0.4 的战乱、流民、逃兵、军粮和匪帮系统。
- **累计安装包**：将来在 **FewerBandits v7.5** 上直接覆盖一次，完整得到《烽烟与暗流》v0.1–v0.5 的全部改动。

## 功能 1：失意贵族秘密资助匪帮袭击军粮

政治恶化的现有王国领主可以秘密利用 v0.4 的**三支真实匪帮**破坏 v0.3 的**现存军粮运输队**：

1. 游戏日达到 25 后，每隔三个游戏日检查一次是否存在候选行动。
2. 资助者必须是非国王、未被囚禁的现役贵族，有合法的 `slot_fb71_cabal_leader`（秘密派系）、`slot_fb71_fief_grievance >= 35`、`slot_fb72_ambition >= 25`，且距上次资助至少 18 天；每个候选领主有 33% 的尝试概率。
3. 目标必须是资助者**本国现存的军粮队**，且目的地城镇的领主是另一个秘密派系的贵族；匪帮距目标少于 28 地图单位。此处体现的是**内部派系为争权破坏本国后勤**，不伪装成外战任务。
4. 只能使用真实存在、空闲且身份匹配的特殊匪帮。与玩家付费委托使用同一个 `slot_af04_order_target`，互斥占用，不会同时接受两份任务。
5. 匪帮在八天内追踪到目标的 5 地图单位内后，调用 v0.4 的真实袭扰逻辑；最多造成 2–4 名军粮护卫减员，并使目的地城镇繁荣度 -1。已有的 4 天袭扰冷却、玩家护送保护、剩余至少 1 人限制继续有效。
6. **只有真实减员成功**后，才记录资助者 ID、受害城镇和事件日期，并增加该贵族现有 v7.4 政治嫌疑 +24。逾期、军粮已抵达、遭其他 AI 消灭或被玩家剿匪阻止，都不会产生成功证据。

所有逻辑都通过原有地图部队、Slot、每日触发器与脚本实现；不新增 troop、party template、场景或阵营。

## 功能 2：玩家的政治案件

前提：玩家必须宣誓效忠某个现有王国，且本国最近 14 日内真的发生过上述政治资助导致的袭扰。

营地新增 **「战争与宫廷：秘密军粮案卷」**，展示是否有未结案的军粮袭扰线索、受害城镇、已知资助者和调查冷却。**没有成功调查时不泄露资助者姓名**。

- **调查**：350 第纳尔，4 天调查冷却，75% 成功率。失败也消耗费用；成功得到对应真实事件的唯一证据令牌，登记在原 v7.4 的 `slot_fb74_intel_strength` 中，案卷显示幕后贵族姓名。
- **向王室递交证据**：对已确认的本国贵族调用 v7.4 的 `fb74_expose`，应用原版宫廷系统已有的王室关系恶化、政治信用与嫌疑惩罚，玩家与国王关系 +3。举报受该系统已有的 7 天揭发冷却约束。
- **收封口费**：同一证据可以择一出售给幕后资助者，得到 650 第纳尔；玩家现有政治嫌疑 +18，幕后贵族对玩家的私人恩怨 +6。
- **防止双重结算**：每次成功袭扰有单独日期令牌；举报与封口都将该令牌标记为已处理。同一案件无法反复举报或售卖。通过 v7.4 的旧宫廷举报对话成功提交同一证据，也会清理 v0.5 的案件令牌。
- **已有宫廷记录联动**：案卷可跳转至 v7.5 政治情报簿，便于继续查看秘密政治、嫌疑与其他情报。

尚未正式调查的案件只显示运粮目的地，不会凭空指定某位贵族有罪。事件仅保留 14 天的可行动期，按现有 v7.4 证据时效保持一致。新版记录不会替换原版玩家与村庄关系或新建“民心”。

## 本轮源代码变更

- 新增 `af05_` 脚本 **8** 个：`daily_plots`, `confirm_strike`, `find_case`, `investigate`, `find_proven_case`, `deliver_report`, `silence_case`, `prepare_ledger`。
- 新增菜单 **2** 个：`af05_ledger`（营地案卷）和 `af05_debug`（作弊测试入口）。
- 新增 24 小时触发器 **1** 个，排在 v0.4 匪帮每日结算之后。
- 新增 Slot **8** 个，编号 **760–767**；未新增全局变量。
- 修改原有 `af04_harass_convoy` 与 `af04_daily_update` 来区分 AI 资助与玩家委托、在真实命中时生成证据；在原版 `fb74_player_report` 成功分支加一条 v0.5 案卷状态同步；营地菜单增加入口。
- 相比 v0.4，只变更 **5** 个编译数据文件：`menus.txt`、`quick_strings.txt`、`scripts.txt`、`simple_triggers.txt`、`variable_uses.txt`。
- 其他 **27** 个数据文件与 v0.4 一致，保留旧全局变量、脚本菜单 ID、原有 troops/party templates 和宫廷对话文本的输出。

## 构建与测试

在源码包根目录执行：

```bash
python build_v05.py
python tests/verify_v05.py
```

此仓库包含 `baseline/v04/compiled` 与 v0.4 源码副本，以便独立重编译。编译器原有三条 `fb7`/`fb73` Script can fail 警告继续存在，本轮无新 `ERROR`。

### 未来统一实机检查

1. 用 FewerBandits v7.5 或 v0.4 已有存档测试旧存档读取、保存，检查新 Slot 的 0 值默认行为。
2. 找到真实战乱地区，等待三支匪帮出现，并在交战王国中观察贵族资助与真实军粮队被袭击。
3. 验证玩家护粮合同与有资助的匪帮袭扰互不干扰，匪帮无法把 NPC 袭扰算作玩家截粮合同的胜利。
4. 验证没有真实军粮减员时，不会出现可举报的政治案件。
5. 成功调查后分别测试举报、封口费、v7.4 旧国王对话举报；每次事件只能兑现一次。
6. 检查非封臣、不同王国、贵族遭囚、匪帮解散、运输队交接或目的地易主时的行为。
7. 运行 120+ 游戏日，检查案件频率、是否被 NPC 自主揭发、是否出现 stale party ID 或重复报酬。

**这些属于后续实机验收任务，本轮并未在游戏客户端验证。**
